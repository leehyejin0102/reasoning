JSON 결과를 Excel로

검사에서 저장한 결과 JSON을 선택하세요.
한 명의 결과를 확인하거나 여러 참가자의 자료를 한 파일로 합칠 수 있습니다.

파일을 선택해 주세요.
  • sessions: 참가자 코드 · 세션 ID · 검사일 · 만 나이 · 검사 언어 · 검사 버전
  • trials: 문항별 응답 · 정답 · 정오답 · 누락/오경보 · 점수 · 반응시간 · 검사별 기록

파일 개수와 관계없이 두 시트로 변환합니다. 요약 점수와 통계량은 R에서 계산하세요. trials의 참가자 코드·세션 ID로 sessions와 연결할 수 있습니다.

선택한 파일은 브라우저 안에서 처리하며 서버에 전송하지 않습니다.
Excel에는 이름·생년월일·완료 여부를 넣지 않습니다. 연령은 검사일 기준 완료된 만 나이입니다.

실시한 문항을 모두 보존합니다(중단·건너뛴 문항은 행이 없습니다). 같은 세션의 동일한 복사본은 한 번만 합칩니다. 검사 코드(task_name): picture_concepts 공통그림찾기 · problem_solving 문제해결 · raven 레이븐 추론 · verbal_cue 언어 단서 결합 · pattern 패턴 검사 · analogy A:B=C:D · rotation 3차원 회전 · picture_arrangement 차례맞추기 · dls 더비셔 · verbal_reasoning 언어적 추론 · number_series 숫자연속추론 · predictive 예측추론 · length 물리적 길이 전이.
