# 샘플(지능검사 v1.0.0)과 이 저장소의 차이

| 항목 | 지능검사 샘플 | 추론능력검사(이 저장소) |
|---|---|---|
| 첫 화면 | 검사 선택·참가자 정보, 언어는 오른쪽 위 버튼 | **표지 → 언어 선택 화면 → 검사 선택·참가자 정보**. 베트남어는 '준비 중' 표시(`readyLanguages`) |
| 검사 선택 | 6개 모두 선택된 상태 | 핵심 8개는 모두 선택된 상태, 보충 5개는 선택 안 된 상태에서 검사자가 눌러 선택(연령 표시만, 자동 선택 없음) |
| 소검사 화면 | 검사마다 따로 만든 페이지(플러그인이 페이지마다 있음) | 13개 페이지가 **공통 엔진(assets/engine.js)** 을 사용. 페이지에는 문구만, 문항은 data.js |
| 소검사 첫 화면 | 일러스트 타이틀 슬라이드 이미지 | 같은 구성(배지·검사명·설명·시작하기)을 코드로 그림. **그림 자리는 비워 두고 자극책자 지시문**을 넣음 |
| 예제 | 슬라이드 데모 + 연습 | 예제 2문항(제한시간 없음)을 직접 풀고, 정답을 주황색으로 표시한 해설 화면을 봄. '설명 다시 보기'로 반복 가능 |
| 자극 | 앱이 그린 자극 / 슬라이드 재현 | **자극책자 PDF 페이지를 그대로 잘라** 쓰고, 보기 칸 위에 투명한 터치 영역을 둠(A:B 는 4지선다 슬라이드, 예측추론은 책자 상자 모양 + 선지 4개) |
| 중지 규칙 | 연속 5문항 0점 | 개발시트대로 **연속 3문항 0점** |
| 음성 | 없음 | 없음(요청에 따라 텍스트만). 개발시트에는 언어 단서·더비셔·예측추론 음성 제시가 적혀 있음 → 추후 녹음 파일로 추가 가능 |
| 엑셀 trials | 38열 | 25열(13개 소검사 공통 열) |

## 확인하지 못한 것

- 실제 DataPipe 서버 저장(전송 요청 형식은 자동 시험에서 가로채 확인). 공식 주소에서 1회 실제 검사로 Google Drive 에 파일이 생기는지 확인 필요.
- 실제 아동·태블릿 기기(iPad Safari)에서의 실시. 화면 크기는 Chromium 에서 PC·태블릿 가로/세로 크기로만 확인.
- 베트남어 화면(미제작).
