# 측정치 정의 (METRICS) — 개발시트 '온라인 검사 구성' 탭 기준

모든 시간은 ms 입니다.

## 반응

| 측정치 | 정의 |
|---|---|
| 정반응 수 | 정답을 맞힌 문항 수 (예측추론: 2점 선지를 고른 문항) |
| 누락오류 수 | 문제 제시 후 제한시간 동안 아무 응답(터치)도 하지 않은 문항 수 |
| 오경보오류 수 | 정답 외의 다른 선택지에 응답한 문항 수. 공통그림찾기·차례맞추기·17·18번처럼 여러 번 고르는 문항에서 일부만 고르고 시간이 지난 경우 포함. **예측추론의 1점 선지도 오경보오류로 셈** |
| 실패 횟수(총 오류 수) | 누락오류 수 + 오경보오류 수 |
| 총점 | 실시 문항의 문항 점수 합 (예측추론 0/1/2점 → 최대 40, 나머지 0/1점 → 최대 20) |
| 부분점수(1점) 반응 수 | 예측추론만: 1점 선지를 고른 문항 수 |
| 정반응 시 응답 변경 횟수 | 정답을 맞힌 문항에서 응답을 바꾼 횟수. 두 번째 선택부터 셈(예: 1 → 4 이면 1회) |
| 오경보오류 시 응답 변경 횟수 | 오답 문항에서 응답을 바꾼 횟수(같은 방식) |
| 응답 변경으로 세는 것 | 보기 1개 문항: 다른 보기로 바꿈 / 공통그림찾기: 이미 고른 줄에서 다른 그림으로 바꿈 / 차례맞추기: '처음부터 다시' 1회 / 길이 17·18번: 이미 채운 칸을 다른 사물로 바꿈 |
| 정확도 | 정반응 수 ÷ 유효 문항 수 |
| 중지 규칙 적용 여부 | 연속 3문항 0점으로 소검사가 중지되었으면 true |

## 시간

| 측정치 | 정의 |
|---|---|
| 첫 반응시간 (`rt`) | 문항 그림이 화면에 그려진 후 첫 응답(첫 터치)까지 |
| 결정시간 (`decision_time`) | 첫 응답부터 '다음'을 누르기까지. '다음'을 누르지 않고 제한시간이 지나면 제한시간 종료까지 |
| 총 반응시간 (`total_rt`) | 첫 반응시간 + 결정시간 |
| 평균 ○○ 시간 | 값이 있는 문항만의 평균 |

## 제한시간 · 중지 규칙 (assets/engine.js)

- 제한시간: 하 20초 · 중 30초 · 상 50초 · 최상 50초(예제는 제한 없음). 남은 5초부터 카운트다운. 시간이 지나면 그때까지의 응답으로 채점하고 자동으로 넘어갑니다.
- 다 풀었으면 '다음'으로 바로 넘어갈 수 있습니다('다음'은 응답이 완성되어야 눌림).
- 중지: 본 문항 **연속 3문항 0점**(시간초과·무응답 포함, 예제 제외) → 남은 문항은 실시하지 않음(`administered=false`).

## 제외 문항 (화면 전환)

문항 도중 다른 탭·창으로 이동하거나 창 크기가 바뀌면 그 문항은 `valid_trial=false` 이고 요약 측정치에서 빠집니다(행은 남음). 연속 0점 중지 규칙에는 포함됩니다.
