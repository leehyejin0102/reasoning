저장 방식
  • 검사가 끝나면 결과 JSON 1개(코드_시각_ID_results.json)가 DataPipe 로 한 번 전송됩니다. DataPipe 실험 설정의 Required fields 는 result 로 두세요.
  • 13개 소검사는 ko/·vi/ 폴더의 화면을 그대로 사용하며, 검사별 문항 CSV 는 이 화면이 JSON 으로 합칩니다.
  • 전송이 불확실하면 결과 화면에서 JSON 을 내려받아 보관하세요. 엑셀은 json_to_excel.html 에서 만듭니다.

설정은 이 브라우저에 저장됩니다. 계정 비밀번호나 Google 토큰은 입력하지 마세요.
